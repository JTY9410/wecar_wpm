도매 API (External)

Base URL: /api/v1/wholesale · 인증: Header X-API-Key 또는 Authorization: Bearer <key>

MethodPath인증설명
GET /health 없음 서비스 상태 확인
GET /prices 키 도매 시세 조회. car1·car2 코드·명칭 모두 허용
GET /lookup 키 car_code 생성 + 매칭 시세. car1·car2 코드·명칭 모두 허용
GET /codes/makers 키 제조사 목록 (car2_code alias 포함)
GET /codes/models 키 모델 목록 · ?maker_no=
GET /codes/modeldetails 키 세부모델 · ?model_no=
GET /codes/grades 키 등급 · ?mdetail_no=
GET /codes/gradedetails 키 세부등급 · ?grade_no=
/prices 쿼리 파라미터
파라미터설명

maker_no, model_no, …계층 코드 (car1 또는 car2)
maker, model, …명칭으로 조회
